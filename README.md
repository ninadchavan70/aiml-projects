# AI/ML Projects

A collection of Python and Jupyter Notebook projects covering programming, data analysis, statistics, and AI/ML concepts.

## Projects

### 1. Customer Order Analysis

Analyzes customer order data to identify spending patterns, product trends, category revenue, and customer insights.

**Skills:**

* Python data structures
* Loops and conditionals
* List and dictionary comprehensions
* Lambda functions
* Sorting and aggregation
* Basic business analysis

### 2. Adventure Game

A Python text adventure game featuring branching paths, user input, validation, and replayable game logic.

**Skills:**

* Use of GitHub Copilot
* Functions
* Conditionals and loops
* String manipulation
* Input validation
* Recursion
* Program structure

### 4. Marketing Campaign Analysis

Analyzes customer demographics, purchasing behavior, campaign responses, and complaints to identify patterns and statistically significant differences.

**Skills:**

* Pandas and NumPy
* Data cleaning
* Missing-value imputation
* Outlier treatment
* Feature engineering
* Exploratory data analysis (EDA)
* Data visualization
* Correlation analysis
* Hypothesis testing
* T-tests
* Customer segmentation
